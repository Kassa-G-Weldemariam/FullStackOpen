# Phonebook Backend (Full-Stack with Frontend) 🌐

**Backend** for the Phonebook app from **Full Stack Open**

This version serves the **full application**: 
- REST API for managing persons (name + number): GET/POST/DELETE endpoints
- Static frontend files from Part 2 (React build in `dist/` folder)
- MongoDB/Mongoose for persistent data (via MongoDB Atlas)

**Features covered**:
- Express server & routing
- Middleware (Morgan logging, CORS)
- Error handling & validation
- Environment variables (.env)
- Serving frontend build statically (via `express.static('dist')`)

## Tech Stack
- Node.js + Express
- Mongoose + MongoDB
- dotenv, Morgan, CORS
- Frontend: React (built to `dist/` from part2/phonebook)

  
**Live Full App:** https://fullstackopen-4tse.onrender.com/
